# TranScr — отчёт об изменениях модуля перевода

## Причина изменений

В предыдущем варианте Google Translate вызывался через неофициальный endpoint `translate.googleapis.com` и отвечал `HTTP 429 Too Many Requests`. Использование `GoogleTranslator` из `deep-translator` само по себе не гарантирует устранения этого ограничения: это библиотека-обёртка над другими переводчиками, а не самостоятельный движок.

## Что изменено

- MyMemory теперь является переводчиком по умолчанию; его HTTPS API вызывается напрямую, без дополнительного wrapper-пакета и без API-ключа.
- Текст разбивается на блоки не более 450 символов для соответствия лимиту MyMemory, а до трёх блоков переводятся параллельно. Ответ API проверяется, HTML-сущности декодируются.
- Блоки, состоящие только из чисел и пунктуации, не отправляются на перевод.
- Добавлен Baidu Translate API: требуется `BAIDU_APP_ID` и `BAIDU_API_KEY`; запросы подписываются MD5 и разбиваются на части, чтобы не превышать лимит стандартного тарифа.
- Сохранены Yandex Cloud, Argos и гибридный MyMemory → Argos.
- Меню и документация обновлены; Google удалён из пользовательского меню и больше не используется как вариант по умолчанию.
- Добавлены тесты для маршрутизации, разбиения текста, MyMemory и Baidu API.

## Ограничения

- MyMemory не является безлимитным. По опубликованной документации MyMemory анонимная квота ограничена примерно 5 000 символов в день; указание email может увеличить квоту до примерно 50 000 символов в день. Эти условия задаёт сторонний сервис, а не TranScr.
- Baidu требует регистрации и API-данных. Стандартный вариант ограничивает частоту запросов, поэтому крупные блоки переводятся последовательно небольшими частями.
- Сетевые запросы к MyMemory и Baidu не проверялись во время локальных тестов; для них используются тестовые ответы. На целевом компьютере требуется подтвердить доступность сервисов.
- Предупреждение Argos `Language en package default expects mwt, which has been added` не является ошибкой, если перевод после него успешно выдан.

## Проверки

Прогнать:

```powershell
python -m unittest discover -s test -p "test_*.py" -v
```

Проверить сетевой перевод на целевом Windows-компьютере отдельно от тестов.
