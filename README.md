## Первый запуск

```powershell
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

Для последующих запусков достаточно последней команды. Windows OCR требует установленного английского языка распознавания `en-US`.

Google Translate работает без ключа. Выберите Google Translate в настройках основным или резервным переводчиком; дополнительные пакеты не нужны. Для Yandex Cloud скопируйте `.env.example` в `.env` и заполните `YANDEX_API_KEY`; `YC_FOLDER_ID` необязателен для API-ключа сервисного аккаунта.

Google подключён через веб-адреса без ключа.
## Использование

1. Выберите OCR и переводчик, нажмите «Запустить переводчик».
2. Нажмите **Alt+T**, чтобы перевести сохранённую область (по умолчанию весь экран).
3. Для разового выбора зоны с переводом можно назначить сочетание «Выделить и перевести» (по умолчанию **Alt+Q**) или оставить поле пустым. После отпускания кнопки мыши перевод запустится автоматически; сохранённая область не изменится. **Esc** отменяет выделение.
4. Перевод сбрасывается любой клавишей либо отдельным сочетанием — по настройкам. Все сочетания меняются в блоке «Горячие клавиши».
5. Нажмите «Остановить», чтобы изменить настройки компонентов.

Снимок сохраняется сочетанием из поля **«Сохранить снимок»**. Поле по умолчанию пустое: горячая клавиша необязательна. Сочетание должно отличаться от остальных действий. Сохранение работает и при остановленном переводчике, а при сбросе «Любая клавиша» само сочетание сохранения не скрывает оверлей.

PNG сохраняются в папку `screenshots` рядом с `main.py`. Имена: `paddle-goog-1.png`, `win-yand-1.png`, `win-argos-1.png`; без запущенного перевода — `empty-1.png`. Счётчик отдельный для каждой связки, продолжается после перезапуска и не перезаписывает файлы. В гибридном режиме в имени указан основной переводчик.

Если перевод виден, сохраняется последний переведённый кадр в размерах его области вместе с тем же растром, который показан на экране. Повторного OCR и перевода нет; исключение оверлея из захвата Windows остаётся включённым. Если оверлей скрыт или перевод ещё не запущен, делается свежий снимок выбранной области без перевода. Сохранение выполняется в фоне, путь к файлу появляется в журнале. Автоматических отладочных снимков больше нет.

PaddleOCR и офлайн-перевод Argos — дополнительные компоненты: `pip install -r requirements-optional.txt` через Python из `.venv`. Для Argos отдельно нужна модель en → ru. Гибрид включает резервный переводчик при ошибке основного.

## Где что находится

- `main.py` — запуск; `core` — управление приложением, настройки, горячие клавиши и пайплайн.
- `modules` — захват, OCR, обработка текста, перевод и оверлей.
- `modules/overlay/rendering.py` — общая растровая отрисовка для приложения и визуальных проверок; `fonts.py` — ограниченный кэш шрифтов.
- `utilities/ui` — окно настроек.
- `utilities/screenshots.py` — сборка PNG с оверлеем и нумерация снимков.
- `logs` — отдельный журнал каждого запуска. Ошибки также видны на вкладке «Журнал».
- Остальное содержимое `test` — временные результаты ручных проверок, исключённые из Git.
- `%LOCALAPPDATA%/TranScr/settings.json` — пользовательские настройки; `.env` — локальные API-данные.

Зависимости: `requirements.txt` нужен для основного запуска; `requirements-optional.txt` — только для PaddleOCR и Argos. Tkinter входит в установку Python, отдельно через pip не устанавливается.

Быстрый режим включён по умолчанию: весь кадр переводится пакетами, без скрытых повторных запросов для отдельных английских фрагментов. При необходимости включите «Дорабатывать неполный перевод (медленнее)». HTTP-клиент или модель Argos готовятся в фоне при запуске компонента, до первого захвата. Готовый резервный перевод хранится 30 секунд; после истечения срока следующий перевод снова обращается к основному провайдеру.
