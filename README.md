# TranScr

Экранный переводчик для Windows 10/11.

## Первый запуск

Установите Python 3.11 с Tkinter и откройте PowerShell в папке проекта:

```powershell
py -3.11 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

Для последующих запусков достаточно последней команды. Windows OCR требует установленного английского языка распознавания `en-US`.

MyMemory работает без ключа. Для Yandex Cloud скопируйте `.env.example` в `.env` и заполните `YANDEX_API_KEY` и `YC_FOLDER_ID`.

## Использование

1. Выберите OCR и переводчик, нажмите «Запустить переводчик».
2. Нажмите **Alt+T**, чтобы перевести сохранённую область (по умолчанию весь экран).
3. Нажмите **Alt+Q** и выделите мышью зону для разового перевода. Он запустится после отпускания кнопки; сохранённая область не изменится. **Esc** отменяет выделение.
4. Перевод сбрасывается любой клавишей либо отдельным сочетанием — по настройкам. Все сочетания меняются в блоке «Горячие клавиши».
5. Нажмите «Остановить», чтобы изменить настройки компонентов.

PaddleOCR и офлайн-перевод Argos — дополнительные компоненты: `pip install -r requirements-optional.txt` через Python из `.venv`. Для Argos отдельно нужна модель en → ru. Гибрид включает резервный переводчик при ошибке основного.

## Где что находится

- `main.py` — запуск; `core` — управление приложением, настройки, горячие клавиши и пайплайн.
- `modules` — захват, OCR, обработка текста, перевод и оверлей.
- `utilities/ui` — окно настроек; `tests` — автоматические проверки.
- `logs` — отдельный журнал каждого запуска с датой и временем в имени. Ошибки также видны на вкладке «Журнал».
- `test/screenshots` — отладочные снимки.
- `%LOCALAPPDATA%/TranScr/settings.json` — пользовательские настройки; `.env` — локальные API-данные.

Проверки: `.venv\Scripts\python.exe -m unittest discover -s tests -v`.

Зависимости: `requirements.txt` нужен для основного запуска; `requirements-optional.txt` — только для PaddleOCR и Argos. Tkinter входит в установку Python, отдельно через pip не устанавливается. Тесты используют стандартный `unittest` и зависимости приложения.
